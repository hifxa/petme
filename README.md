# PetMe App

An android application designed keeping in mind busy lives of petowners.
Packed with tons on features, this application has a 
- Homepage having 4 different cards for different features
  - Map embed view for pet shops/vet locator
  - Checklist creater for tasks like feed, walk vet appointment, etc.
  - A lost and found section where pet owners can post ads for lost pets. Similarly others can post ads for found pets.
  - An adoption section where interested people can contact ads posted by other people/pet owners.
- Next section that lets pet owners to create pet profile. There can be many for one pet owner to create. They can also customise profile colors for different pets.
- Another section where we have a chat support availabe where pet owners can chat with other owners for reasons like pet get-together, walks, mating etc
- Login/Logout functionality.
- Onboarding screens.
- Contact us page.
